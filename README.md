# Backend-Environment-Workspace

My workspace for **Application Development I** at Carlow University.
It holds my assignments, experiments, and notes for building applications with Node.js, Express, Java, and SQL.

## 1. Workspace Overview

| Area | Details |
|------|---------|
| Languages | JavaScript (Node.js), Java, SQL, HTML/CSS |
| Frameworks | Express.js |
| Database | Relational (SQL) |
| Tools | Git, GitHub, VS Code |
| Environment | Windows 11 |

## 2. Learning Objectives

By the end of the semester, I will be able to:

- [ ] Create, execute, and debug backend scripts
- [ ] Build RESTful APIs with full CRUD operations
- [ ] Be able to request processing, sessions, and authentication
- [ ] Design role-based access control and permissions
- [ ] Use Git for version control and code management
- [ ] Design relational databases to store, query, and manipulate data
- [ ] Build web pages that integrate with backend services
- [ ] Read, write, and analyze code and documentation

## 3. How I Plan to Use This Repo

- **Assignments:** one folder per project, each with its own README
- **Notes:** class notes and concept summaries in `.md` files
- **Git habits:** small, frequent commits with clear messages;
  branches for larger features
- **Progress tracking:** tick off the objectives above as I complete them
- **Debugging log:** record bugs I hit and how I fixed them
